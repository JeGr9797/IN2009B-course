# IN2009B Optimization Course Material

This repository contains Jupyter notebooks and supporting material for the IN2009B course. The content focuses on mathematical optimization models and computational implementations in Python.

## Course contents

The repository is organized into three main modules:

### 1. Location
- P-median
- P-center
- P-dispersion
- Uncapacitated Facility Location Problem (UFLP)
- Capacitated Facility Location Problem (CFLP)
- Stronger formulations for CFLP

### 2. Production and Capacity
- Dynamic lot-sizing
- Flexibility design problem

### 3. Routing and Scheduling
- Traveling Salesman Problem (TSP)
- Efficient TSP formulations
- Vehicle Routing Problem (VRP)
- Capacitated Vehicle Routing Problem (CVRP)
- CVRP with PyVRP
- Job Shop Scheduling
